Download SonixApp

Install Sonix as a standalone app for your computer or Android phone. Each package launches in its own app window, so you don’t need to open a browser tab.

FLATPAK

Fedora & Arch Linux

64-bit Flatpak app. Version 0.1.5 opens Sonix directly in its own GTK/WebKit window and includes an in-app retry screen for connection failures.

Download Flatpak ↓
DEB

Debian & Ubuntu

64-bit DEB package. Open the downloaded file with your package installer. WebKitGTK 4.1 is required; Ubuntu 24.04 or later is recommended.

Download DEB ↓
EXE

Windows 10 & 11

Windows 10 and 11 installer. It adds Start Menu and desktop shortcuts and opens Sonix in a dedicated app window. Microsoft Edge is used as the app runtime. This preview installer is unsigned.

Download EXE ↓
APK

Android

Android 8 or later. Install the APK to add Sonix to your apps. The app uses Android’s native WebView window and requests mic or camera access only when you enable those features.

Download APK ↓

Current packages: Fedora/Arch Flatpak and Debian/Ubuntu DEB 0.1.5; Android APK 0.1.3; Windows 10/11 installer 0.1.1. Linux apps open directly in a Sonix window. All packages need an internet connection. Cross-device QR sign-in and Google Authenticator-compatible two-factor codes require the Sonix account server.
